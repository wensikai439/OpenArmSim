# 完整视觉抓瓶流程

右手抓下半瓶身 → 双手交接 → 右手退出 → 左手放入篮子 → 松爪撤离。旧 TAMP 演示和上一版右手抓取实验都保留，新流程不调用它们的抓取、交接或放置宏。

## 启动

在项目根目录运行：

```bash
./run relay
```

录像、原生物理评分、图像证据与工具记录保存在自动生成的 `runs/relay-*`。可用 `--case case.json --output runs/新目录` 指定初始条件，或用 `--program` 检查其他候选程序。已有目录不会覆盖。

这是独立的完整 skill 入口，尚未替换首页聊天的旧技能路由。它调用官方 ASPIRE 执行器和新的原生 MuJoCo 执行器，没有启动真机或修改公司电脑。

## 结构

| 模块 | 作用 |
| --- | --- |
| program.py | 根据图像和当前机器人状态组合基础工具；分支处理闭爪丢失和运输偏差，不保存某个瓶位的关节轨迹。 |
| visual_geometry.py | 由 RGB 工具标记和机器人 FK 在线估计投影，再估计篮口中心；不读取模拟器相机矩阵或物体真值。 |
| visual_relay.py | 独立 IK、带载笛卡尔姿态插值、平滑加减速和实测到位检查；没有旧 TAMP 动作调用。 |
| relay_benchmark.py | 固定代码与条件，逐例运行，保留失败，生成完整原速视频与评分页面。 |

## 平滑控制（v3）

- 用有界的 C2 B 样条替换 IK 路径点之间的直线拼接；带瓶路径的笛卡尔采样间距从 12 mm 缩到 6 mm。
- 根据采样的速度、加速度和 jerk 重新分配时间，并以零速度、零加速度起停。名义轨迹目标为 0.6 rad/s、2 rad/s²、20 rad/s³；这是规划目标，不是接触冲击或真机运动的认证上限。
- 记录实际关节位置、速度、末端位置与夹爪时序。对比统计使用实际时间戳和 14 个手臂关节的原始差分，包含接触影响，不用视频观感代替测量。

新的结果与原速视频在 `runs/20261026-smooth/index.html`。六个条件与 v2 配对回归，不再称为未见测试；耗时与接触尖峰都完整报告。较慢夹爪及受阻后限压的候选出现失抓或更大的局部冲击，未采纳；原夹爪控制、物理参数与评分保持不变。

本轮 6/6 完整任务通过；六例配对的实际关节 jerk RMS 中位数下降 54.1%，95 分位下降 70.7%。整套动作从原来的 48–52 秒延长为 66–82 秒。两个样本的局部接触 jerk 峰值仍增加约 2.3% 和 17.0%，因此没有宣称消除了接触抖动。

单例运动对比：

```bash
.venv/bin/python -B tools/relay_motion.py \
  --baseline runs/20261026-relay/validation-v2/nominal \
  --candidate runs/20261026-smooth/validation/nominal \
  --output runs/20261026-smooth/motion.json
```

## 上一版修正（v2）

- 小步纠偏减少固定停顿，并复用已有图像估计；长距离带载移动按连续末端姿态规划。
- 右手松爪后先向下退出瓶身，再回右侧；避免撤手不够或横向扫到瓶子，干扰左手运输。
- 移动工具核查实际 TCP，偏差超过 8 mm 不返回成功；交接区域由初始双手位置计算，避免瓶位变化后运输过界。
- 只有运输到位误差允许有界恢复：重新观测并确认右爪仍受阻，再用实际位置规划接瓶。其他错误继续停止，不重置世界。
- 左手夹持证据缺失时，程序保持供物手，不继续释放；闭爪受阻只是本体反馈代理，最终由独立原生物理评分核验。

## 验收与复现

```bash
.venv/bin/python -B tools/relay_benchmark.py \
  --protocol skills/bottle_visual/relay/evaluation.json --output runs/relay-suite
```

通过要求同时满足：程序完成、右手下半瓶身接触、实际抬升、双手夹持、右手脱离后左手持瓶、整瓶入篮、双手释放、篮底支撑并稳定至少一秒。沿用原生物理门槛，没有改质量、摩擦、增益或评分。

上一版结果与原速视频：`runs/20261026-relay/index.html`。首轮完整测试及运输偏差反例保留在该目录的 `validation/`，v2 验收在 `validation-v2/`；不同样本不合并宣称成功率提升。

## 适用条件

仍是已知直立黑瓶、固定白篮、两路固定合成 RGB 和虚拟平面工具标记。瓶身尺寸、接瓶高度和篮深含工程先验；没有验证任意物体、移动篮子、严重遮挡或真机迁移。

新适配器显式使用机器人模型的夹爪全行程，与 ACT 等学习策略的记录动作范围分开；这个模型范围不是经过真机认证的电机限位。没有把超出学习策略范围的动作悄悄裁剪后当成 VLA 成功。

Haiku 基于工程控制器与失败记录审阅了程序。原始第二次修订存在“过晚读取初始姿态、失败后重复抬升”的问题，审查拒绝后由 Codex 修正；记录在 `runs/20261026-relay/model/review.json`。本实验没有训练神经网络。
