恢复如何发生

01 · 闭爪没有执行

编码器仍接近张开端点，允许一次原位补闭爪。只有真实夹持成立才抬升。

02 · 闭爪却抓空

打开空夹爪，实际运动回已验证的接近点；新观测、新候选、新路径，不恢复世界快照。

03 · 接收手未夹住

右手继续持瓶；左手补夹，确认双手夹持后才松右手。未知碰撞、失稳和超时停止。

证据边界

这是一份带专家纠正的程序凝练实验，没有训练神经网络权重。模型在线修复在开发的三类故障中成功两类；接收手故障时误选动作，之后通过专家轨迹和静态审查纠正。所有失败稿和原始记录保留。

输入仍是仿真几何真值。感知偏差在首次失败后撤除，属于合成诊断，不能当作真实视觉重定位。规划 / API 等待期间仿真暂停；没有验证连续实时闭环、倒瓶重抓、任意物体或真机迁移。远程电脑和硬件均未操作。
