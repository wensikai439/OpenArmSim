# OpenArm Lab

OpenArm 仿真与 LLM 任务平台。两人通过浏览器使用实验室 4090 上的同一套场景；当前仅运行仿真。

## 1. 打开平台

在浏览器打开 **[OpenArm Lab](https://excellence-nylon-falls-seeks.trycloudflare.com)**，输入团队共享的网页登录密码。队友不需要 SSH 权限。

这是临时 HTTPS 地址，通道重启后地址会变化；需要稳定网址时，由管理员提供正式域名或网络入口。同一浏览器会记住登录；主动退出、清除 Cookie 或更换浏览器后需重新登录。

## 2. 首次接入模型

1. 首次使用填写姓名或昵称、个人实验目录名、API 地址、模型名称和自己的 API Key；Key 可在[零词元密钥页面](https://zzq.si/keys)获取。默认地址是 `https://zzq.si/v1`，也可填写自己的请求地址。
2. 如果模型支持图像输入，可勾选该选项；确认所填地址、模型与 Key 后，点击 **确认并保存**。
3. 以后可通过左侧 **接入模型 / API 配置** 查看或修改配置；需要时点击 **测试连接**。每人的配置按浏览器独立保存，不要把 Key 提交到 GitHub。

发送任务会调用所填模型；启用图像输入时，头部和左右腕相机画面也会发送给该模型。

## 3. 操作与查看结果

- 在左侧输入任务并点击发送，例如：`让右手末端向上移动3厘米，保持朝向。` 也可以点击示例任务，再发送。
- 右上查看场景，可切换头部、左腕和右腕相机；**留帧**保存当前画面，**重置**恢复场景。自由视角只改变观察角度。
- 右下 **运行阶段**查看进度，**关键帧**查看过程；需要中止时点击 **停止**。结束后可通过“实验设置与记录”查看实验记录。
- 场景由大家共享，一次执行一项任务；开始新任务或重置场景前，先确认队友没有在使用。

## 4. 数据和协作

实验记录保存在服务器各自的个人目录；代码和使用说明放 GitHub。目录名由首次使用时填写，平台自动区分不同浏览器。清除浏览器 Cookie 或换用新浏览器后会建立新的个人目录，原记录保留在服务器。

开发时各自创建分支，测试后提交 PR，请队友检查再合并。4090 更新器每 60 秒检查 GitHub `main`，空闲时验证并切换代码，失败则回退；本地提交须先推送才会被服务器看到。容器重启后需启动一次更新器，详见部署说明。
