# 目录与设备范围

所有agent/robot新增文件、环境、缓存、配置和日志只允许放在本LLMHarness目录。其他远程文件只能读；不得修改ACT/DP/π0.5、驱动、权重、系统环境、权限或网络设置。

禁止上传仿真平台、MuJoCo、仿真模型、网页和训练数据。默认命令只读检查或无设备软件服务；未得到新的明确现场执行授权，禁止打开相机、查询CAN、使能电机、初始化或发运动命令。不要导入旧相机模块进行检查，它在模块体中枚举设备。

API密钥只在.private/api.json，权限600、父目录700；禁止打印、打包、写日志或Git。临时文件放.runtime/tmp，日志放records。不得写系统服务、定时任务、系统密钥环或默认全局缓存。

真实动作必须有新鲜实测定位、含不确定度的下半瓶身夹持证据、同ACT初始姿态验收、完整双臂携物碰撞规划、持续控制和硬件看门狗验收；现场操作员在场。程序完成、驱动返回、闭爪和仿真成功均不能代替真机成功证据。

整理只移动或清理本项目拥有且可追溯的内容，旧版本留在records/versions中。不要删除其他原有文件。
