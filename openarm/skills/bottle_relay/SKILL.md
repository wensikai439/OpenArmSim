# 抓瓶交接 v2

目标：右手抓起已登记的直立瓶子，交给左手，再放进当前篮子。

## 执行

使用同目录 `program.py`，由 NVIDIA ASPIRE ProgramExecutor 注入注册工具。先检查 `manifest.json` 的程序哈希和能力范围。`./run aspire test --x .59 --y -.29` 是隔离仿真测试，不访问真机，也不需要 API。

1. 新观测确认持瓶手。无人持瓶必须确认瓶子直立后右手抓取；右手持瓶则继续交接；左手持瓶则进入放置。其他状态拒绝运动。
2. `pick(arm='right', hold_seconds=2, next_handover={'to_arm':'left'})`。工具完成后重新观测，确认右手独立持瓶。
3. `handover(from_arm='right', to_arm='left', hold_seconds=2, placement_aware=True)`。以当前几何搜索接收手抓姿，并检查篮子放置端点与下降连接；原生双手夹持、供物手释放、撤离和接收手持稳仍须成立。
4. 重新确认左手独立持瓶，`place(arm='left', receptacle_id='basket', shape_clearance=True)`；用实测手—瓶关系重新搜索直立携物姿态和连续下降路径。
5. 工具失败或新观测与回执不符立即报错，不自动重置、盲目重试或额外松手。最后的文字回执不是完整任务成功判定；成功来自独立的物理验收。

## 证据与边界

新24组条件的48次成对测试：旧版15/24、新版22/24；位置变化10/12→12/12；组合压力5/12→10/12。新版修复9例，也有2例旧版通过而新版失败（813放置IK失败；817交接搜索失败）。这两个反例保留在报告，不能隐藏。额外CLI检查在(0.52,-0.20)交接搜索失败，单独记录在审计，不计入已冻结24组。

输入为仿真几何真值，机器人、瓶子模型及碰撞参数均为候选模型。18×20cm是采样区域，不保证区域内任意连续位置。朝向、篮子偏移、质量/摩擦变化为工程压力测试，不能替代真实标定。原生测试均从空手开始；续接分支另外通过逻辑契约检查，不表示任意中断状态都能恢复。

改进主要来自工程增加的下游几何约束、抓姿搜索及 LLM 生成的受检组合，没有训练神经模型权重。旧TAMP演示保持；v1保存在 `history/v1/`。真机需用真实感知与工具驱动替换仿真适配器，不能直接发送仿真关节指令。部署步骤见项目 `docs/真机部署.md`。
