每个录像目录包含 `video.mp4`、`frames.json`、`result.json` 和 `recording.json`。播放器支持播放速度、阶段跳转、关键片段和下载；三个视角显示同一时刻。

原实验没有连续录像。这四段来自相同冻结案例和技能程序的原生物理复跑，逐步动作、前后状态、时间及阶段结果均与原记录完全一致；不计为新增测试成功率。6 Hz 采样，按仿真时间播放，省略规划暂停。仅本地运行，没有操作真机。

## 重新录制

`tools/record_skill.py` 只增加旁观渲染，不改变策略输入或物理控制。输出必须是 `runs/` 下的新目录；核对不一致时返回非零退出码。

录制需要包含 H.264 编码器的 FFmpeg；当前本地工具位于 `.runtime/video-encoder/imageio_ffmpeg/binaries/`，由 `imageio-ffmpeg==0.6.0` 提供，未修改训练环境依赖。也可通过 `--encoder` 指定已有 FFmpeg。

```bash
PYTHONDONTWRITEBYTECODE=1 MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
.venv/bin/python -B tools/record_skill.py \
  --trial runs/20261024-precision/final/heldout/precision/1200 \
  --output runs/new-recording \
  --encoder .runtime/video-encoder/imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2
```

播放器模板为 `tools/skill_videos.html`；复制到包含 `nominal`、`regrasp`、`receiver`、`baseline` 四个录像子目录的文件夹，命名为 `index.html` 即可。录像和原生实验输出留在已忽略的 `runs/`，源码工具、模板和本说明由 Git 管理。此次没有修改既有交付 ZIP。
