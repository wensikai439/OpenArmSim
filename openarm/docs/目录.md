# 仓库目录

| 路径 | 内容 | 工作目录 |
| --- | --- | --- |
| `openarm/` | OpenArm仿真、控制、任务与部署工具 | `OpenArmSim/openarm` |
| `松灵机械臂/phyagentos/` | PhyAgentOS、控制台、PiPER适配与Skill | `OpenArmSim/松灵机械臂/phyagentos` |

`openarm/openarm_mujoco/`包含原固定提交的机器人描述和许可证，来源见其SOURCE.json。

既有服务器按原目录部署时，仓库目录整理不会搬动服务器数据。下一次迁移时将OpenArm工作目录设为`openarm/`；本目录内的更新器可从新仓库结构单独提取OpenArm代码。
