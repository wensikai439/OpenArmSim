# 协作交接

1. 代码统一放在私有仓库：https://github.com/wensikai439/OpenArmSim；仅受邀成员可访问。
2. 各自在本机开分支开发、测试，提交 PR，由另一人检查后合并到 main；这是协作约定，目前未启用强制分支保护或自动 CI。
3. 4090 已部署完整运行代码、ACT、cuRobo 和依赖，目录仅限 `/data_ssdb/wsk/OpenArmSim`；不改其他人的文件或进程。
4. 服务器由目录内更新器跟随 GitHub `main`，每 60 秒检查一次。有人执行任务时等待；空闲后验证代码并切换，启动失败恢复上一版。只在本机提交不会触发更新，需先推送到 GitHub。容器重启后须重新启动更新器。
5. 浏览器打开 [OpenArm Lab](https://excellence-nylon-falls-seeks.trycloudflare.com)；这是临时公网地址，通道重启后会变。
6. 同一浏览器记住登录；首次填写姓名、个人实验目录名、请求地址、模型与 Key；配置和记录目录按浏览器区分，仿真场景共享。
7. 实验记录保存在服务器个人目录：`runs/users/目录名-浏览器标识/`；代码与操作说明放 GitHub。
8. 同一时刻执行一项任务；清除 Cookie 或换浏览器会建立新目录，已有记录保留在服务器。
9. API Key、登录凭据、实验记录、运行数据库和缓存不提交 GitHub；应另外备份服务器数据。
10. 队友提供 GitHub 用户名后，由仓库所有者发送协作邀请；平台运行和访问说明见 `deploy/server/README.md`。
