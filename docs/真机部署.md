## 当前版本

纯真机发行包为 `handoff/OpenArmRobot-20261025-r6.1.zip`，保留冻结 skill v5，固定 NVIDIA ASPIRE 官方执行器。r6 补齐真实工具提供者、相机与 CAN 适配、原网格/FCL 检查、平滑轨迹、独占会话和异常停止。

环境改为本目录内的 Python 3.10 虚拟环境，只读复用原机器人环境的 OpenCV/ArUco、RealSense、CAN、NumPy、SciPy；新增 FCL 安装仅在此虚拟环境。同一 API 配置原样保留，不复制或打印密钥。

```sh
./run prepare deps
./run check
./run verify
./run preflight
./run service
./run chat "检查真实服务准备情况，不要运动"
```

上述检查不启动设备。`service` 默认是无设备服务；只有经过独立实测验收并显式选择设备会话，才允许真实动作。标定与碰撞配置可以独立维护，验收绑定代码、参数与几何摘要；修改后旧验收失效。

## 证据范围

本地/远程无设备回归包含慢滑、日志失败、保护检查异常、阻塞反馈、错误规划结果、会话争用、初始化前的路径拒绝，以及冻结程序的正常流程/接收恢复。真实 URDF 与网格仅用于离线几何/IK检查，不代表已经完成实物抓取。

SDK 已成功导入；实际相机、CAN 和电机未启动。仍需现场测量相机外参/曝光对时、物体与夹爪几何、夹持阈值和相对抓姿，并完成分段动作与硬件看门狗验收。原始 URDF 的 0.3 mm 占位碰撞球不能替代这些工作。

公司端入口、数据采集与现场步骤见 [部署说明](../deploy/ROBOT.md) 和 [试运行](../deploy/试运行.md)。本轮发布、检查及原文件保护证据保存在 `runs/20261025-real/` 与公司端 `records/`。只有实测结果才能更新真机成功标记。

重新打包使用 `.venv/bin/python -B -m tools.package_robot`；部署更新使用 `.venv/bin/python -B -m tools.install_robot 压缩包路径`。更新先备份清单所属文件，保留 API、环境和用户标定，不覆盖未知文件。
