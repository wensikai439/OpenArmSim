## 后台反馈

每次原生记录额外保存 `internal.jsonl` 和 `internal-summary.json`，记录关节目标与反馈、夹爪反馈、物体位置、接触、持稳时长、力和穿透。采样不修改控制、物理状态和时钟，不写进学习策略的观测，也不在主页面增加说明或小字。记录失败会写入错误事件，不替代原始执行结果。

默认学习策略的夹爪范围保持原样。仅独立诊断脚本的 `--native-gripper` 允许使用已有仿真手指范围，不裁剪夹爪输出，不将该范围说成真机实测极限。ACT 权重未改动，检查点七个文件的 SHA256 已与 SSH 源逐个核对一致。

ACT 原始基线有一个诊断计数遗漏：`timing.policy_commands=0` 不准确，实际执行了 128 步；原始结果保留，诊断脚本已补上提交计数。ACT 的相机画面和真实初始分布仍有差异，三组失败不能用来单独归因于模型或仿真。

## 重跑与使用

在项目根目录运行：

```bash
./run check
PYTHONDONTWRITEBYTECODE=1 MUJOCO_GL=egl .venv/bin/python -B -m tools.sim_check
./run status
```

快检默认新建一个带时间的 `runs/*-grasp-check/`，使用独立环境，不抢占页面里的任务。平台入口仍为 <http://127.0.0.1:8767/>，后台服务使用 `./run keep` 恢复。

本轮 SSH 仅用于读取及导出检查点、部署日志和少量视频帧，没有在公司电脑创建文件、安装依赖、连接控制器或操作真机。相机标定、物体参数与控制器的独立实测验收留待抓瓶迁移阶段完成。

记录结构参考 [ASPIRE 的运行产物设计](https://github.com/NVlabs/ASPIRE/blob/main/docs/run-artifacts.md)；ACT 输入与动作块对照 [官方 LeRobot ACT 实现](https://github.com/huggingface/lerobot/blob/main/src/lerobot/policies/act/modeling_act.py)。
