# 瓶身抓取

当前独立 ASPIRE 恢复技能为 v3：右手抓下半瓶身，左手接上部瓶身，最后放进篮子。原固定 TAMP 演示保留。

- 入口：`./run aspire recover`，默认位置为 `(0.50, -0.21)`；不连接真机，不调用模型 API。
- 抓姿按瓶身自身比例采样，不使用固定世界高度；实际有力接触须落在瓶身，不能用瓶盖或瓶颈充当成功。
- 感知偏差造成抓错部位时，只有原生接触确认瓶子静止支撑在桌面上，才允许松开、实际退回并重抓。
- 左手接过负载时补偿负载重力对应的关节参考偏移；不修改模型质量、摩擦、控制增益或物理状态。静止持瓶下沉超过5mm额外判失败。

新取6个位置，标称与组合压力共12种条件全部通过；3个旧失败回归通过。最大静止下沉3.20mm。相同1400条件，关闭补偿下沉32.65mm，开启后1.76mm；未关闭稳定性门槛来接纳对照。

初始候选9/12通过，失败和源码仍保留在 `runs/20261024-body/`；最终冻结协议、统计及原生记录在其 `final/`。368项平台回归通过，默认CLI完整任务通过。两段视频逐步动作/状态与对应原生试验完全一致，完整解码通过。
