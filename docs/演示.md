# 演示操作

页面：<http://127.0.0.1:8767/>。左侧输入任务，右上观察，右下查看模型制定的阶段与关键帧。

## 开始

平台已设置为持续运行，关闭终端或 Codex 不会关闭它；开机后由用户服务恢复。

```bash
cd /home/wsk/gpt+vla/OpenArmSim
./run status
```

若未启动，运行 `./run keep`。API 配置已保存在系统密钥环中；页面“API 配置”可手动修改或删除，不用每次输入。

默认桌面只有黑瓶子、篮子和桌子。每个独立演示前点右上“重置”，等待上一项任务结束后再发送下一项。三个示例按钮仅填入文字，点击发送才执行，也可以直接描述自己的目标。

## 可直接输入

- `让右手末端向上移动3厘米，再让左手末端向前移动4厘米，保持各自朝向。`
- `用右手把黑瓶子向机器人正前方移动8厘米，放回桌面，松手并撤离。`
- `把黑瓶子抓起来，放到桌面的世界坐标XY=[0.533, -0.253]米处，松手并撤离。你选择合适的手臂。`
- `把桌上的黑瓶子放进篮子，放好后松手并撤离。`

左右以机器人自身为准，机器人正前方为世界 +X，左侧为 +Y，上方为 +Z；自由视角不会改变这些方向，也不改变模型看到的固定三路相机。

模型通过真实 API 观察、制定阶段、调用技能并复查。TAMP 根据当前场景重新求解；物体依靠 MuJoCo 接触运动。执行与阶段完成要有对应原生回执，模型文字或工具正常退出不能代替物理成功。

## 遇到问题

- 目标必须在可达、无碰撞的工作区内。不可达目标会被拒绝；不能保证任意三维位置、任意物体都能完成。
- HTTP 429/502/503/504 最多重试两次推理，仍受调用次数与时间预算约束。401/402 等错误不会反复请求；检查页面配置或服务商状态。
- 若任务失败，先展开调用记录检查原因。等任务终止后重置，再开始独立演示；不要连续点击发送或在运动中重置。
- 右上“实验详情”和“记录与设置”保留内部反馈；关键帧可点击查看。具体测试结果见[验收记录](../runs/20261014-demo/index.html)。

查看服务日志：`./run logs`。只有需要结束平台时才使用 `./run stop`，该命令同时关闭自动启动并释放睡眠保护；`./run keep` 可重新启用。没有新增定时任务。

本演示只控制本地仿真。TAMP 使用显式仿真几何；ACT/cuRobo 的连接状态与任务效果分别记录，π0.5 尚未接入。独立实物标定和 sim-to-real 尚未验收。
