# 仿真工作台

UI 和执行器优化统一放在 `harness-youhua`，由原 `refactor/harness-runtime` 重命名；`main` 保持原提交。

## 参考与取舍

- [RPent Dashboard](https://rpent.readthedocs.io/en/stable/rst_source/guides/dashboard.html)：在同一任务会话中观察相机、工具调用和执行时间线。我们的对话保留工具证据，主视图区常驻三路模型观测。
- [RPent 执行架构](https://rpent.readthedocs.io/en/stable/rst_source/development/architecture.html)：区分规划、执行和环境反馈。界面继续区分模型复查、技能完成与完整目标成功。
- [OpenHands](https://github.com/OpenHands/OpenHands)：参考控制中心和工作区的组织方式，把任务交互与环境视图分开。
- [Open WebUI](https://github.com/open-webui/open-webui)：参考侧栏导航和聚焦对话的呈现，把模型、记忆等次要设置移出主画面。

这些是界面组织上的设计参考，没有引入上述项目的代码、模型或后端依赖。

## 布局与操作

| 区域 | 用途 |
| --- | --- |
| 左侧导航 | 打开技能、记忆、实验记录与模型配置 |
| 任务对话 | 填写目标、查看模型回复和可展开的工具记录；示例按钮只填入文本 |
| 实时场景 | 操作者视角和三路模型相机；支持切换视角、留帧、重置 |
| 执行过程 | 显示原有计划、执行反馈与完成条件 |
| 关键帧 | 查看实际保存的帧，点击后打开原有大图对话框 |

场景右上角可展开画面，按 Esc 或再次点击还原。标签支持左右方向键、Home 和 End。窄窗口改为纵向布局，全部操作仍可滚动访问。

## 文件职责

- `ui/index.html`：页面结构，保留原有功能控件的 ID 与对话框。
- `ui/workspace.css`：工作台布局、颜色、响应式规则；`styles.css` 继续提供已有组件样式。
- `ui/workspace.js`：标签切换、场景展开、侧栏入口和连接状态显示，不调用机器人或模型。
- `ui/app.js`：沿用原来的 API 请求、图像刷新和证据更新，只接入新的展示模块。
- `ui/agent.js`、`ui/scene.js`、物理引擎、控制器、规划器、评分与部署配置：本次 UI 修改未改动。

本地预览为 <http://127.0.0.1:8775/>，只监听回环地址，使用独立对话数据库和仅本会话的模型配置。不会自动调用 LLM。预览服务和验证材料位于 `.runtime/ui-preview/`；原有服务没有重启。

检查了页面原有 ID 完整、无重复 ID，JavaScript 语法通过。现有执行合同与服务器检查共 9 项通过。浏览器验证覆盖标签、键盘、场景展开与还原、侧栏入口、相机切换、不同窗口宽度和实际关键帧。
